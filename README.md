# one-person-media-company

Grok Bot / Cursor skill: Hermes-style one-person media loop.

**Source article:** [How to Build a One-Person Media Company With Hermes Bots](https://x.com/VibeMarketer_/status/2093330541177352217) (@VibeMarketer_)

## What it does

Input a topic → shared vault → scout → research → human angle gate → approval-ready post draft **+ image-generation prompt** → no auto-publish.

## Install / use

Copy `SKILL.md` into your agent skills folder (or open this repo as a skill package). Invoke with something like:

> 用 one-person-media-company 跑「墨西哥幽默」

Vaults land under `/home/box/agent-data/media-company-<topic-slug>/` on Grok Bot.
